# Session Protocol (for Claude, ChatGPT, Codex, designers)
## Start
1. [[HOME]] → latest note in 07_Sessions → [[03_Docs/GBA2026_Context.md]].
2. [[Rules & Red Lines]] + [[Design System]] (fonts, colours, tokens, prompt template).
3. Target deliverable note + its current revision, linked feedback and assets.
4. Verify the real files, fonts and repo state; state target, baseline and acceptance checks. Never guess an approval.
## End
1. Save outputs without overwriting approved files; new REV note; QA evidence.
2. FB notes resolved/linked; DEC notes for choices; promote to RULE only with approval evidence.
3. Skill lessons → [[Skill Improvement Log]].
4. Handoff note in 07_Sessions ([[TPL-Session-Handoff]]): changed files, blockers, next action, commit.
5. Copy to 09_GitHub_Repo, push, deploy mock site; report status accurately.
